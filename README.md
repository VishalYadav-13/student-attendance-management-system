## 🏛️ Executive Overview

The **Student Attendance Management System (SAMS)** is engineered for polytechnic institutes, colleges, and university departments. It modernizes institutional attendance tracking by eliminating outdated paper registers and proxy roll calls. 

Featuring **Google Gemini AI image quality assessment**, mathematical landmark biometric matching, strict OWASP security controls, automated 75% attendance shortage warning monitors, and full compliance reporting, SAMS delivers a production-grade experience for Administrators, Teachers, and Students.

---

## 🌟 Key Features

### 1. 🛡️ Role-Based Access Control (RBAC)
- **Administrator Dashboard**: Institute-wide KPIs, faculty directories, student management, system configuration, audit trails, and automated shortage warning rosters.
- **Teacher Dashboard**: Real-time daily timetable, classroom attendance studio (AI Camera + Manual Grid), batch marking, and class reports.
- **Student Dashboard**: Cumulative attendance dial, individual subject progress bars, critical shortage alert (<75%), interactive monthly attendance calendar, and biometric privacy controls.

### 2. 📷 AI-Assisted Face Verification & Biometric Privacy
- **Webcam Integration**: Browser-based camera stream using `navigator.mediaDevices.getUserMedia`.
- **Liveness & Quality Checks**: Multi-step pipeline (Looking for face ➔ Face detected ➔ Checking quality ➔ Verifying identity ➔ Attendance confirmed).
- **Gemini AI Vision**: Server-side quality analysis for blurriness, lighting, and multiple-face detection without exposing API credentials.
- **Zero Raw Image Storage**: Only irreversible mathematical landmark feature hashes are retained. Raw camera footage is never stored.
- **Right to Erasure**: Students can delete their biometric profiles at any time.

### 3. 📊 Interactive Analytics & Shortage Alarms
- **Dynamic Visualizations**: Chart.js charts for weekly trends, department comparisons, and attendance status distributions.
- **Automated Shortage Warning**: Triggers warnings for students below the institutional threshold (default 75%).
- **Natural Language AI Insights**: On-demand executive summaries generated by Google Gemini.

### 4. 🔒 Enterprise Security & Auditability
- **Bcrypt Encryption**: Native `password_hash()` and `password_verify()`.
- **Prepared Queries**: 100% PDO parameterized SQL queries preventing SQL injection.
- **Duplicate Prevention**: Database unique constraint `(session_id, student_id)` rejects duplicate marking attempts.
- **Audited Manual Overrides**: Teachers can correct records with mandatory change explanations permanently logged into `attendance_overrides`.
- **Stateless Bearer JWT & Secure Sessions**: Dual support for Bearer tokens and HttpOnly cookies.

## 🛠️ Technology Stack

- **Frontend**: HTML5, CSS3, Vanilla JavaScript (Modular ES6 architecture), Chart.js
- **Backend**: PHP 8.2+, REST API Router, Clean Service/Controller Architecture

## 🚀 Quickstart (Local Development)

### 1. Clone the Repository
```bash
git clone https://github.com/VishalYadav-13/student-attendance-management-system.git
cd student-attendance-management-system
```

### 2. Configure Environment
```bash
cp .env.example .env
```
*(Optional: Add your `GEMINI_API_KEY` to `.env` to enable live Google Gemini AI capabilities).*

### 3. Launch Development Server
```bash
php -S localhost:8000 backend/public/index.php
```

### 4. Open in Browser
- **Portal Landing Page**: [http://localhost:8000/frontend/index.html](http://localhost:8000/frontend/index.html)
- **Sign In**: [http://localhost:8000/frontend/login.html](http://localhost:8000/frontend/login.html)
